# Мониторинг septik-tmn.ru

Каждые 5 минут GitHub Actions проверяет сайт и шлёт письмо, если он упал.

## Что проверяется

| Проверка | Что означает сбой |
|---|---|
| DNS домена | домен не оплачен / проблемы с NS Beget |
| TCP-соединение с сервером :443 | лежит хостинг |
| Главная и `/catalog/`: код 200 | сайт отдаёт 500/502/503/404 |
| На странице есть «578-058» и «Эко-Групп» | хостинг отключил аккаунт и показывает заглушку |
| Нет «DB query error», «Fatal error» и т.п. | сломалась база или PHP |
| Время ответа < 15 сек | сайт сильно тормозит |
| Раз в сутки: SSL > 14 дней, домен > 30 дней | скоро истечёт сертификат или оплата домена |

Перед тем как признать сбой, делается 3 попытки с интервалом 20 сек, чтобы не было ложных тревог.

## Какие письма приходят

- 🔴 **septik-tmn.ru НЕДОСТУПЕН**: сразу при падении, с причиной.
- 🔴 **всё ещё недоступен (N ч)**: каждые 3 часа, пока сайт лежит.
- ✅ **снова работает**: при восстановлении, с длительностью простоя.
- ⚠️ **истекает SSL / оплата домена**.

Если сломается сам мониторинг (например, неверный пароль почты), GitHub пришлёт владельцу репозитория письмо о проваленном запуске.

## Установка (один раз, ~10 минут)

### 1. Пароль приложения для почты

Отправлять письма можно с любого почтового ящика. Нужен **пароль приложения**, обычный пароль не подойдёт.

| Почта | Где получить пароль | SMTP_HOST | SMTP_PORT |
|---|---|---|---|
| Gmail | myaccount.google.com → Безопасность → Пароли приложений (нужна двухэтапная аутентификация) | `smtp.gmail.com` | `465` |
| Mail.ru | Настройки → Безопасность → Пароли для внешних приложений | `smtp.mail.ru` | `465` |
| Яндекс | id.yandex.ru → Безопасность → Пароли приложений → Почта | `smtp.yandex.ru` | `465` |

### 2. Репозиторий на GitHub

1. Создайте **публичный** репозиторий, например `septik-monitor`. В публичных репозиториях Actions бесплатны без лимита. В приватном 5-минутные проверки съедят бесплатные 2000 минут в месяц примерно за неделю.
   В коде нет паролей, они хранятся в секретах (шаг 3) и снаружи не видны.
2. Загрузите туда содержимое этой папки, включая `.github/workflows/monitor.yml`.

### 3. Секреты

Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**:

| Имя | Пример |
|---|---|
| `SMTP_HOST` | `smtp.gmail.com` |
| `SMTP_PORT` | `465` |
| `SMTP_USER` | `ваш.ящик@gmail.com` |
| `SMTP_PASSWORD` | пароль приложения из шага 1 |
| `MAIL_TO` | кому слать, можно несколько через запятую: `septik72@mail.ru, ...` |

### 4. Проверка

**Actions → «Мониторинг septik-tmn.ru» → Run workflow → отметить «Отправить тестовое письмо» → Run**.
Должно прийти письмо «✅ Тест мониторинга». Если не пришло, проверьте папку «Спам» и лог запуска.

Дальше проверки идут сами каждые 5 минут.

## Настройка

Все параметры собраны в начале [monitor.py](monitor.py): список страниц, маркеры, таймауты, интервал напоминаний.
Если на сайте сменится телефон, поменяйте маркеры в `PAGES`, иначе придёт ложное «сайт недоступен».

Локальный прогон без отправки писем: `python monitor.py --dry-run`
